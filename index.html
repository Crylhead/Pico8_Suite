How the tools talk to each other

  • Library (button at the top right): every saved image and palette, with Open in… for every tool that can use it. Drag a library thumbnail onto a tool's canvas to load it there.
  • Pixel Studio → Tile Maker / fade preview: File → Send to.
  • Tile Maker → Pixel Studio: Export → Tile Sprite Sheet → Library, then open it in Pixel Studio.
  • Palette & Fades → Pixel Studio: the palette panel's “From Palette & Fades” button, or save the palette to the library.
  • Any image → code: Data Tools turns library images into PICO-8 string literals.
  • Line Tool → library: Pixels → Library saves the drawn lines as an image; Trace library image shows any library image under the lines.

Desktop tools outside the suite

Historical desktop tools from Demotools are not bundled in this standalone repository.

    One-time setup required
    
        
    The Minifier engine files are not prepared in this Suite folder yet. Run python tools/package_minifier.py once from the Suite folder (Python 3.9+), then choose Retry engine or reload this page. The first run downloads the pinned engine (or uses the pinned archives); afterwards everything works offline.
    
        
    After that, just open index.html directly (Chrome or Edge); no server or launcher is needed. Start_Pico8_Suite.bat remains optional and serves the Suite at http://127.0.0.1:8000.
    
        
    Your Library and browser sessions belong to each address: opening index.html directly and the launcher address keep separate data. Export a Library backup to move between them. Original files are unchanged.
